# Руководство пользователя Bura

## 1. Назначение приложения

Bura — мобильное Android-приложение для просмотра прогноза погоды, хранения избранных мест, обращения в поддержку и расчёта качества радиосигнала между двумя городами. Приложение использует погодные и геокодинговые данные Open-Meteo, а функции аккаунта, избранного, поддержки и радиотестов работают через сервер Bura.

## 2. Требования

- Android 9.0 или новее.
- Подключение к интернету для входа, регистрации, поиска городов, обновления прогноза, синхронизации избранного, отправки сообщений в поддержку и запуска радиотестов.
- Учётная запись Bura.

> В отладочной сборке сервер ожидается по адресу `http://10.0.2.2:8080/`, что удобно для Android Emulator при локально запущенном сервере.

## 3. Первый запуск, регистрация и вход

1. Запустите приложение Bura.
2. Если вы ещё не вошли в аккаунт, откроется экран входа.
3. Для существующего аккаунта:
   - введите почту;
   - введите пароль;
   - нажмите **«Войти»**.
4. Для нового аккаунта:
   - нажмите **«Регистрация»**;
   - введите почту, имя и пароль;
   - нажмите **«Зарегистрироваться»**.
5. После успешного входа откроется основная навигация приложения.

Если вход или регистрация не удались, проверьте подключение к интернету, правильность почты и пароля. При повторной ошибке обратитесь в поддержку.

## 4. Основная навигация

После входа в нижней панели доступны разделы:

- **Главная** — текущая погода, прогноз, сводки и переход к графикам.
- **Избранное** — список сохранённых мест.
- **Аккаунт** — данные профиля, статистика и управление учётной записью.
- **Поддержка** — переписка с поддержкой.
- **Радиосигнал** — расчёт качества радиосвязи между двумя городами.

## 5. Главная: прогноз погоды

На главном экране отображаются погодные данные выбранного места:

- текущая температура и состояние погоды;
- ощущаемая температура;
- почасовой прогноз;
- прогноз по дням;
- осадки и вероятность осадков;
- ветер;
- давление;
- влажность;
- восход и закат;
- УФ-индекс;
- видимость.

### 5.1 Выбор места

1. Нажмите кнопку выбора места или строку поиска места.
2. Введите название города.
3. Выберите нужный результат из списка.
4. Приложение загрузит прогноз для выбранного места.

Если результатов нет, уточните название города или попробуйте написать его на другом языке. Если приложение сообщает об отсутствии интернета, подключитесь к сети и повторите поиск.

### 5.2 Обновление прогноза

Прогноз загружается из сети и кэшируется на устройстве. Если данные устарели или загрузка не удалась:

1. Подключитесь к интернету.
2. Нажмите **«Try again» / «Повторить»**, если кнопка доступна.
3. При необходимости заново выберите место.

### 5.3 Графики и подробный прогноз

Из главной страницы можно открыть экран графиков:

- нажмите на почасовой блок, чтобы перейти к подробным графикам;
- нажмите на день в дневном прогнозе, чтобы открыть графики с выбранной датой;
- нажмите на блок осадков, чтобы перейти к деталям по осадкам.

## 6. Избранные места

Раздел **Избранное** позволяет быстро открывать сохранённые города.

### 6.1 Добавление места в избранное

1. На экране выбора места найдите город через поиск.
2. Выберите город.
3. Нажмите значок сердца рядом с выбранным местом.
4. Место появится в списке избранных.

### 6.2 Открытие избранного места

1. Перейдите в раздел **Избранное**.
2. Выберите нужный город.
3. Приложение откроет главную страницу с прогнозом для этого города.

### 6.3 Удаление места

1. Откройте список избранных или экран выбора места.
2. Выберите удаление для нужного города.
3. Подтвердите удаление.

При удалении избранного места также удаляется связанный с ним кэш прогноза на устройстве.

## 7. Настройки

Настройки открываются с главного экрана через кнопку настроек. В настройках можно изменить единицы измерения и тему оформления.

### 7.1 Единицы измерения

Доступны следующие параметры:

- температура: градусы Цельсия или Фаренгейта;
- ветер: м/с, км/ч, мили/ч или узлы;
- осадки: миллиметры, сантиметры или дюймы;
- дождь, ливни и снег: отдельные единицы отображения;
- давление: гектопаскали, дюймы ртутного столба или миллиметры ртутного столба;
- видимость: километры, мили, метры или футы.

Чтобы изменить единицу:

1. Откройте **Настройки**.
2. Нажмите нужный параметр.
3. Выберите вариант в диалоге.
4. Подтвердите выбор.

### 7.2 Тема оформления

Доступны темы:

- тёмная;
- светлая;
- системная тема.

При выборе системной темы приложение следует настройкам Android.

## 8. Аккаунт

В разделе **Аккаунт** доступны сведения профиля и действия с учётной записью.

### 8.1 Просмотр профиля и статистики

На экране аккаунта отображаются:

- имя пользователя;
- адрес электронной почты;
- количество избранных мест;
- количество радиотестов;
- наличие обращений в поддержку.

### 8.2 Изменение имени

1. Откройте **Аккаунт**.
2. Нажмите действие изменения имени.
3. Введите новое имя.
4. Сохраните изменения.

### 8.3 Изменение пароля

1. Откройте **Аккаунт**.
2. Нажмите действие изменения пароля.
3. Введите новый пароль.
4. Сохраните изменения.

После смены пароля используйте новый пароль при следующем входе.

### 8.4 Выход из аккаунта

1. Откройте **Аккаунт**.
2. Нажмите **«Выйти»**.
3. Приложение очистит текущую сессию и вернёт вас на экран входа.

### 8.5 Удаление аккаунта

1. Откройте **Аккаунт**.
2. Выберите действие удаления аккаунта.
3. Подтвердите удаление.

Удаление аккаунта удаляет связанные с ним избранные города, радиотесты и сообщения поддержки на сервере. Это действие необратимо.

## 9. Поддержка

Раздел **Поддержка** предназначен для переписки с администраторами.

### 9.1 Отправка обращения

1. Откройте **Поддержка**.
2. Введите имя, почту и текст сообщения, если поля доступны.
3. Нажмите отправку сообщения.
4. Сообщение появится в истории переписки.

### 9.2 Просмотр ответов

1. Откройте **Поддержка**.
2. Приложение загрузит текущую переписку.
3. Ответы администратора отображаются в общем списке сообщений.

### 9.3 Удаление переписки

Если доступна кнопка удаления, нажмите её и подтвердите действие. После удаления история обращения будет удалена для вашего аккаунта.

## 10. Радиосигнал

Раздел **Радиосигнал** рассчитывает качество условной радиолинии между двумя городами с учётом расстояния, частоты и текущих погодных условий.

### 10.1 Запуск теста

1. Откройте **Радиосигнал**.
2. В поле первого города начните вводить название и выберите город из подсказок.
3. В поле второго города выберите второй город.
4. Укажите частоту в МГц, если поле доступно.
5. Запустите тест.

После расчёта приложение покажет:

- расстояние между городами;
- качество сигнала в процентах;
- задержку;
- примерную скорость;
- историю предыдущих тестов.

### 10.2 Интерпретация результата

Высокий процент качества означает лучшие условия радиолинии. На результат влияют расстояние, частота, влажность, дождь, облачность и температура. Значения являются расчётной оценкой и не заменяют профессиональное радиопланирование.

## 11. Работа без интернета

Без интернета приложение может показывать ранее загруженные данные, если они ещё доступны в кэше. Для следующих действий интернет обязателен:

- регистрация и вход;
- обновление прогноза;
- поиск городов;
- синхронизация избранного;
- отправка и получение сообщений поддержки;
- запуск новых радиотестов.

## 12. Типичные проблемы и решения

### Не удаётся войти

- Проверьте правильность почты и пароля.
- Проверьте подключение к интернету.
- Если аккаунт был удалён, зарегистрируйтесь заново.

### Не загружается прогноз

- Подключитесь к интернету.
- Повторите загрузку.
- Выберите место заново.

### Город не находится

- Уточните название.
- Попробуйте название на английском или языке страны.
- Проверьте интернет-соединение.

### Сессия неожиданно завершилась

Если сервер вернул ошибку авторизации, приложение очищает сессию. Войдите в аккаунт повторно.

### Радиотест не запускается

- Убедитесь, что оба города выбраны из подсказок, а не только введены вручную.
- Проверьте подключение к интернету.
- Укажите корректную частоту.
