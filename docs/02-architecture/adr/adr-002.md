# ADR-002: Использовать нативный Android + Jetpack Compose

**Статус:** Принято  
**Дата:** 31.05.2026  
**Источник:** раздел «Архитектурные решения» в [`arc42-overview.md`](../arc42-overview.md)

## Контекст

Bura — мобильный проект, ориентированный на Android. Приложению нужны современный UI, навигация между экранами прогноза, графиков, аккаунта, избранного, поддержки, радиотеста и настроек, а также интеграция с локальным хранилищем и Android SDK.

## Решение

Реализовать клиентскую часть как нативное Android-приложение на Kotlin с Jetpack Compose, Material 3, Navigation Compose, Room, Retrofit и Kotlinx Serialization.

## Обоснование

Нативный Android + Jetpack Compose дает современный декларативный UI, интеграцию с Android SDK, поддержку Material 3 и удобную связку с Room, ViewModel-подходом, Retrofit и Kotlin-экосистемой.

## Последствия

### Положительные

- UI строится декларативно и проще связывается с immutable/sealed состояниями экранов.
- Material 3 обеспечивает современный внешний вид приложения.
- Room, SharedPreferences и Android APIs доступны без дополнительных прослоек.
- Kotlin и Compose упрощают разработку экранов и переиспользуемых компонентов.

### Отрицательные / ограничения

- Приложение ориентировано на Android и не является кроссплатформенным.
- Требуется актуальная Android Studio и Android SDK.
- Команда должна учитывать особенности жизненного цикла Android и Compose state management.
