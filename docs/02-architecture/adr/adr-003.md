# ADR-003: Использовать Spring Boot backend

**Статус:** Принято  
**Дата:** 31.05.2026  
**Источник:** раздел «Архитектурные решения» в [`arc42-overview.md`](../arc42-overview.md)

## Контекст

Bura требует серверной части для регистрации и входа пользователей, JWT-аутентификации, ролей USER/ADMIN, хранения избранных городов, обращений в поддержку, истории тестов радиосигнала, пользовательской статистики и административной панели.

Backend должен быстро предоставлять REST API, validation, security, persistence и OpenAPI-документацию.

## Решение

Использовать Spring Boot backend на Java 21 со Spring Web, Spring Security, Spring Data JPA, Validation и SpringDoc OpenAPI.

## Обоснование

Spring Boot позволяет быстро реализовать REST API, security, validation, JPA-доступ к данным и OpenAPI-документацию. Экосистема Spring подходит для учебного проекта с backend-частью и хорошо поддерживает тестирование JUnit/Spring Security.

## Последствия

### Положительные

- Быстро создаются REST controllers и JSON-контракты для Android-клиента.
- Spring Security предоставляет стандартную основу для JWT-защиты endpoints.
- Spring Data JPA упрощает repository layer.
- SpringDoc автоматически публикует Swagger UI/OpenAPI.
- JUnit и Spring test utilities подходят для проверки контроллеров, сервисов и security.

### Отрицательные / ограничения

- Нужно поддерживать конфигурацию Spring Security, JPA и окружений запуска.
- Backend требует JVM и отдельного процесса при локальной разработке.
- Ошибки DTO-контрактов между Android и backend нужно отслеживать в документации и тестах.
