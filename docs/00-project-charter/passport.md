## 2. БИЗНЕС-КОНТЕКСТ

**Проблема:** Пользователям необходимо удобное мобильное приложение для отслеживания погодных условий и метеорологических данных с возможностью персонализации, сохранения избранных локаций и получения детализированной информации по различным параметрам (температура, влажность, давление, УФ-индекс, осадки и др.).

**Решение:** Система Bura предоставляет кроссплатформенное мобильное приложение на Android с современным интерфейсом (Jetpack Compose), которое синхронизируется с серверной частью на Spring Boot. Приложение поддерживает многопользовательский режим с JWT-аутентификацией, управление избранными городами, настройку тем оформления, отправку сообщений в поддержку и отображение расширенных метеоданных через модульную архитектуру.

---

## 3. ЦЕЛИ ПРОЕКТА

• Создать мобильное приложение для Android с интуитивным интерфейсом для отображения погодных данных

• Реализовать серверную часть с системой аутентификации, управлением пользователями и хранением данных

• Обеспечить модульную архитектуру приложения для поддержки различных метеорологических параметров (температура, влажность, давление, УФ-индекс, осадки, видимость, ветер и др.)

• Предоставить пользователям возможность персонализации (темы оформления, избранные локации, настройки единиц измерения)

• Реализовать систему обратной связи через службу поддержки

## 5. КЛЮЧЕВЫЕ РИСКИ

• Риск 1: Зависимость от внешних API погоды — стратегия реагирования: реализация кэширования данных через Room Database и офлайн-режим работы

• Риск 2: Безопасность пользовательских данных — стратегия реагирования: использование JWT-токенов с истекающим сроком действия, Spring Security для защиты endpoints, хранение секретов через .env конфигурацию

• Риск 3: Фрагментация Android-устройств — стратегия реагирования: тестирование на минимальном SDK 28+, использование Material 3 и Jetpack Compose для консистентного UI

## 6. ТЕХНОЛОГИЧЕСКИЙ СТЕК

- Gradle 8.14.3

## 7. МОДУЛЬНАЯ СТРУКТУРА

### Android-приложение включает модули:
- `auth` — аутентификация пользователей
- `account` — управление аккаунтом
- `place` — работа с локациями и избранными городами
- `summary` — сводные погодные данные
- `temperature`, `humidity`, `pressure`, `uvindex`, `precipitation`, `visibility`, `wind`, `gust`, `pop` — отдельные метеопараметры
- `graphs` — визуализация данных
- `sun`, `forecast`, `condition` — дополнительные данные
- `settings`, `support`, `radio`, `units` — вспомогательные функции

### Сервер включает модули:
- `account` — управление пользователями и ролями
- `favorite` — избранные города
- `security` — JWT-аутентификация
- `support` — сообщения поддержки
- `signal` — тестирование радиосигналов
- `stats` — статистика пользователей
- `admin` — администрирование
